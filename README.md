# 🔗 URL Shortener

A simple and efficient URL Shortener web application that converts long URLs into short, shareable links. This project demonstrates backend development, API handling, and database integration.

---

## 🚀 Features

- Shorten long URLs into compact links  
- Redirect short URLs to original URLs  
- Copy shortened URL with one click  
- Simple and clean user interface  
- Fast and lightweight performance  

---

## 🛠️ Tech Stack

- **Backend:** Node.js / Express (update if different)
